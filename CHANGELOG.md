# Changelog

All notable changes to CyberWarEnv will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [v2.1.0] — 2026-10-03

### Added
- Extended the factorial registry from **n=10 to n=20** seeds per (cell, algorithm)
  condition (**160 total runs** across 10 experiment directories).
- New experiment directories:
  - `EXP-2026-000009` (corporate/scripted/DQN seeds 10–19)
  - `EXP-2026-000010` (corporate/scripted/PPO seeds 10–19)
- New scripts:
  - `paper_scripts/extend_to_n20.py` — n=10 → n=20 extension worker with fixed
    `run_id` assignment (deterministic `run_{seed+1:03d}` instead of `run_{N+1}`)
    to prevent overwriting existing run folders.
  - `paper_scripts/fix_corp_scripted.py` — re-runs the corporate/scripted
    extension in dedicated experiment directories to avoid `run_id` collisions
    with the data-center/adaptive extension.
  - `paper_scripts/fix_manifests.py` — idempotent manifest synchronizer that
    re-computes `config_hash` and `artifact_hash` when `RESUME` re-writes
    `config.json` with a new `created_utc`.

### Changed
- `paper_analysis.py` and `paper_figures.py` now operate on the full 160-run
  registry; output statistics and figures are regenerated byte-identically.
- All inferential statements in the manuscript updated to reflect n=20 values.
- README updated with v2.1.0 release notes, new results table, and citation block.

### Verified
- All **320 SHA-256 hashes** (160 `config_hash` + 160 `artifact_hash`) verified as
  PASS by `paper_scripts/verify_registry_integrity.py`.
- `paper_analysis.py` regenerates `paper_analysis.json` byte-identical from the
  extended registry.
- `paper_figures.py` regenerates all three publication figures byte-identical.

### Statistical impact
- All four per-cell Wilcoxon signed-rank tests now significant at Holm-corrected
  p ≤ 1.1×10⁻³ (was p ≤ 0.018 at n=10).
- Pooled exact Wilcoxon test over 79 seed-paired differences: PPO wins 73, DQN wins 6,
  1 tie, **p < 10⁻¹⁵** (was p = 1.9×10⁻⁹ at n=10).
- Hedges' g effect sizes remain in the "large" band (1.03–2.54; was 1.56–3.01).

## [v2.0.0] — 2026-10-02

### Added
- Initial public release.
- Gymnasium-compatible CyberWarEnv environment with two topologies (corporate 18
  nodes, data center 20 nodes), three attacker profiles (scripted, probabilistic,
  adaptive), three sensor configurations (A/B/C), 9-action SOC-triage action space,
  and a shaped reward with operational-impact costs.
- 80-run factorial registry (`EXP-2026-000001` through `EXP-2026-000008`) covering
  2 topologies × 2 attacker profiles × 2 algorithms × 10 seeds.
- Pre-registered difficulty calibration: 12-cell sweep with explicit criteria
  (C1–C3) and a published trade-off when no cell satisfies all criteria.
- Exact statistical battery: paired Wilcoxon signed-rank, independent Mann–Whitney,
  Hedges' g with small-sample correction, rank-biserial correlation, Wilson score
  intervals, Holm-Bonferroni correction across the family of four cells.
- Three publication figures: calibration sweep, training curves, final CSR comparison
  with Wilson intervals.
- Full SHA-256 provenance chain: every run folder carries `config.json`,
  `results.json`, `manifest.json` (with `config_hash` and `artifact_hash`),
  and the trained `model.zip`.
- Paper artifact chain scripts: `extend_runs.py`, `paper_analysis.py`,
  `paper_figures.py`, `verify_paper_provenance.py`, `verify_registry_integrity.py`,
  `build_manifest.py`.
- Bilingual (Arabic + English) documentation in `PACKAGE_README.md`.
- Step-by-step GitHub publishing guide in `PUBLISH_TO_GITHUB.md`.
- Exact software stack documented in `ENVIRONMENT.md` and recorded per-run in
  every `config.json`'s `software_versions` field.

### Statistical summary (v2.0.0, n=10 seeds per cell)
- PPO reached a higher mean CSR than DQN in all four cells.
- Holm-corrected per-cell p-values between 0.0078 and 0.018.
- Hedges' g between 1.56 and 3.01 (all "large" by Cohen's convention).
- Pooled exact Wilcoxon p = 1.9×10⁻⁹, g = 1.74.
